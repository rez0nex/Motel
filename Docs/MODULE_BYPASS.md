# Обход сгоревшего модуля

Текущий прототип: фиксированное поле 4 × 4 внутри открывающегося шкафа расширенной технической. Вариант с амперами отменён. С 13 ноября 2026 команды перенесены на генератор; кнопки «Пуск» в окне поля больше нет. Текущая расстановка и ручной маршрут — [TECHNICAL_ROOM.md](TECHNICAL_ROOM.md). До приёмки — без сборки и Git-цикла.

## Правила

E открывает панель, клик поворачивает секцию на 90° по часовой стрелке. Сигнал входит в B1 с запада и должен выйти из B4 на восток в блок запуска. Подсвечиваются только секции, достигнутые через взаимно совпадающие соединения. B2 сгорела, неподвижна и не проводит сигнал; пустые ячейки не поворачиваются. Лишние секции подключать не требуется. Координаты приведены только здесь и в коде, интерфейс их не показывает.

| Ячейка | Начальные соединения |
| --- | --- |
| B1 | W + N |
| A1 | N + E |
| A2 | N + S |
| A3 | N + E |
| B3 | W + E |
| C3 | S + W |
| C4 | S + E |
| B4 | W + N |
| A4 | W + E |
| C2 | W + E |

Слева показан «Вход», справа — «Блок запуска», инструкция — «Клик — повернуть секцию». Доступ к полю появляется только после полного открытия дверцы шкафа. Физические секции и подсветка используют ту же модель BypassCircuit, что и окно; закрытие сохраняет повороты до конца попытки.

Все команды находятся на генераторе. Зелёный **«Пуск»** при разрыве показывает «Не работает…», при решении включает индикатор неинтерактивного блока пуска и сообщает «Цепь восстановлена. Перегрев сохраняется». Он не запускает аварию. Жёлтый **«Перезапуск»** принимается и при разрыве, и при решении: после прежней задержки **2,5 игровые секунды** запрашивает общий взрыв. Повторное нажатие не создаёт второй запрос. Пауза замораживает задержку; штатный таймер может опередить её.

Пока поле открыто, время идёт, управление/действия с миром блокируются. «Закрыть» возвращает управление, Escape включает обычную паузу. Сброс возвращает исходное поле, закрывает дверцу/крышку и восстанавливает индикаторы. Красное отключение требует двух действий: поднять прозрачную крышку, затем отдельно нажать кнопку. Диагностика справа независима, безопасна и даёт свежие показания Вадиму только в этой попытке.

Прежнее наблюдение об обходе и последующем взрыве сохраняется после завершённой аварии от перезапуска с собранной цепью, без дублей. Перезапуск с нерешённой цепью не выдаёт ложное знание об успешном обходе. Ручной reload до аварии/штатный таймер, опередивший перезапуск, не приписывают себе эту причину. Пользовательское сохранение не очищается. Решение панели не требуется для эвакуации; текущий финал и восемь секунд после четверых описаны отдельно в [ENDING_PROTOTYPE.md](ENDING_PROTOTYPE.md).

## Создание и ручная проверка

См. [README](../README.md#техническая-комната) и [TECHNICAL_ROOM.md](TECHNICAL_ROOM.md). Основная сцена — `Assets/Scenes/MotelBlockout.unity`; генератор — `Motel → Create Motel Blockout` с подтверждением перезаписи. Отдельная команда `Motel → Update Technical Room` обновляет только техническую в сохранённой основной сцене.

## История проверок прежней версии (12 ноября 2026)

- **Код написан, компиляция проверена:** окончательные runtime/Editor и прежняя геометрия — PASS (`Logs/Bypass-Final-Compilation.txt`). Независимая проверка фиксированных масок, поворота, входа/выхода, разорванного маршрута, неподвижных ячеек и необязательных секций прошла.
- **Фактически проверено автоматически в Unity Play Mode:** CharacterController прошёл от стойки через дверь технической к панели/записке; проверены первые лучи до 2,5 м. Прочитана точная записка без выдачи диагностики/факта. Открытое поле блокирует управление, время идёт; закрытие сохраняет секции. Пауза останавливает время/повороты/задержку. Решение без пуска безопасно; явный пуск однократен и возвращает управление.
- **Авария/сохранение:** два завершённых пусковых взрыва дали один факт; задержки 2,502/2,508 игровые секунды (обычный/ускоренный режим). Проверены таймер при открытом поле, выигрыш таймера перед задержкой, отсутствие второго взрыва, ручной reload до взрыва без факта, восстановление поля/игрока/дверей, отдельные диагностика и отключение. Старый JSON с семью фактами расширяется без потерь/дублей и без вывода нового знания из прежних записей. Отчёт — `Logs/Bypass-PlayChecks.txt`. До штатного 20:22 тест доводил часы граничной установкой 359,85 с в фикстуре; полные 360 настоящих секунд заново не ожидались, игровая длительность не менялась.
- **Регрессия эвакуации:** один физический маршрут четверых без решения/пуска панели — 164,85 активных секунд, обычная настройка 360 секунд и прежние скорости. Использован дубликат ключей со стойки; второй источник ключей этим прогоном не засчитывается. После общей аварии восстановилась сцена, осталось семь прежних фактов без нового факта обхода. Отчёт — `Logs/Bypass-Evacuation-PlayChecks.txt`.
- **Фактический визуальный просмотр:** просмотрены кадры разорванного и полного маршрутов в Game View (частичная/полная подсветка, состояния «Пуск»), а также статический кадр панели/записки в технической. Материалы/текст читаются на этих кадрах. Это не ручная игровая приёмка.
- **Ручная проверка пользователем:** 2026-11-12 пользователь подтвердил, что вручную запускал панель и нажимал «Пуск». После автопрогонов в пользовательском JSON появился только новый флаг `bypassStartCausedExplosion: true`; сверка подтвердила сохранность всех прежних данных. Файл оставлен с новой записью, без отката/перезаписи агентом. Это подтверждение ручного пуска, а полная приёмка этапа ещё не заявлена.
- **Ограничения:** автотесты вызывают обработчики после проверки геометрии/луча, а не нажимают физические E/мышь. Время чтения человеком не входит в замер эвакуации. Оставшиеся пункты ручного маршрута — поведение при разрыве/закрытии/паузе, повторный пуск и таймер с открытым полем. UnityConnect и остальные защищённые файлы совпали по хешам; временный мост убран из Assets. Windows-сборка, коммит, push и слияние не выполнялись.
